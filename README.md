# NimbusCode Soluciones Informáticas S.R.L.

## Módulo de Gestión Comercial y Facturación

### Documentación técnica del proyecto

## 1. Descripción del proyecto

NimbusCode Soluciones Informáticas S.R.L. es una empresa ficticia dedicada al desarrollo de soluciones informáticas para pequeñas y medianas empresas.

El proyecto consiste en el diseño de un Módulo de Gestión Comercial y Facturación destinado a centralizar la información de clientes, presupuestos, facturas y seguimiento de cobranzas.

La propuesta busca reducir las tareas manuales, evitar la dispersión de información en distintas planillas y mejorar la organización y trazabilidad de las operaciones comerciales.

## 2. Objetivo del sistema

Facilitar la gestión de las operaciones comerciales mediante un sistema que permita registrar clientes, elaborar presupuestos, emitir facturas y realizar el seguimiento de los estados de pago.

## 3. Alcance funcional

El módulo contempla:

- Registro y consulta de clientes.
- Elaboración y seguimiento de presupuestos.
- Registro de detalles y conceptos presupuestados.
- Emisión y consulta de facturas.
- Seguimiento del estado de las cobranzas.

## 4. Entidades principales

El modelo de datos contempla las siguientes entidades:

- Cliente
- Presupuesto
- DetallePresupuesto
- Factura

## 5. Organización del proyecto

El trabajo se desarrolla tomando como base las entregas anteriores del Trabajo Práctico Integrador:
